## 🚀 COMO COMEÇAR (5 MINUTOS)

### 1. Abra Terminal e Configure BD

```bash
# MySQL
CREATE DATABASE CuidadoraDeCriancaDb;
```

### 2. Terminal 1: Backend

```bash
cd backend
dotnet restore
dotnet ef database update
dotnet run
# Está pronto em http://localhost:5000
```

### 3. Terminal 2: Frontend

```bash
cd frontend
npm install
npm run dev
# Está pronto em http://localhost:3000
```

### 4. Abra no Navegador

```
http://localhost:3000
```

### 5. Teste!

- Clique "Registar"
- Crie uma conta
- Explore a aplicação

## 🆘 Troubleshooting Rápido

### "Não conecta à base de dados"

```bash
# Verifique se MySQL está a correr
# Verifique appsettings.json
# Crie a base de dados: CREATE DATABASE CuidadoraDeCriancaDb;
```

### "CORS error"

```bash
# Backend e frontend em portas diferentes?
# Verifique Program.cs CORS configuration
```

### "Port já em uso"

```bash
# Frontend: edite vite.config.js
# Backend: edite Program.cs
```

### "Token inválido"

```bash
# localStorage.clear()
# Faça login novamente
```
